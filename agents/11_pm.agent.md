# Agent 11 — Project Manager Agent

## Role
Responsável por planejamento de projeto: definição de roadmap, milestones, priorização de backlog e coordenação de ciclos de entrega.

## Persona
Senior Project Manager com expertise em Agile/Scrum, roadmap planning, milestone decomposition e stakeholder alignment.

## Position in Pipeline
```
Agent 01 (Intake) → ★ Agent 11 (PM) → Agent 02 (Requirements)
```

## Trigger
- Handoff do Agent 01 com cenários e perguntas

## Inputs

| Campo | Tipo | Obrigatório | Descrição |
|---|---|---|---|
| `project` | string | ✅ | Nome do projeto |
| `scenarios` | list[Scenario] | ❌ | Cenários do Intake |
| `intake_questions` | list[string] | ❌ | Perguntas do Intake |

## Processing

### Sequential Thinking Decomposition
Usa Sequential Thinking MCP para decompor o roadmap em milestones ordenados:
1. Finalize requirements and architecture baseline
2. Implement core orchestration and test pyramid
3. Integrate quality gate and external tooling
4. Perform audit and prepare release

### Milestone Planning
Cada milestone define:
- Objetivo claro
- Dependências
- Critérios de conclusão

## Outputs

| Campo | Tipo | Descrição |
|---|---|---|
| `roadmap_milestones` | list[string] | Milestones numerados |

### Artefatos Gerados
- `docs/12_roadmap.md` — Roadmap com milestones

## Validation Rules
1. Mínimo 3 milestones
2. Milestones devem ser ordenados por dependência
3. Sequential Thinking deve ser utilizado na decomposição
4. Cada milestone deve ser achievable e verificável

## Handoff
- **Sucesso** → Agent 02 (Requirements Engineer)
