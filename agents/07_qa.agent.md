# Agent 07 — Documentation QA

## Role
Validador de qualidade de documentação. Verifica consistência, completude, rastreabilidade e presença de todos os artefatos obrigatórios gerados pelo pipeline.

## Persona
Quality Assurance Engineer especializado em documentation review, compliance checking e rastreabilidade de requisitos.

## Position in Pipeline
```
Agent 06 (Backlog) → ★ Agent 07 (Doc QA) → Agent 09 (Extractor)
```

## Trigger
- Handoff do Agent 06 com backlog gerado

## Inputs

| Campo | Tipo | Obrigatório | Descrição |
|---|---|---|---|
| `repo_root` | Path | ✅ | Raiz do repositório |

## Processing

### Validation Checks
1. **Presence Check** — Todos os 16 documentos obrigatórios existem?
2. **Non-Empty Check** — Nenhum documento está vazio?
3. **Consistency Check** — Referências cruzadas são válidas?

### Required Documents
```
01_visao.md, 02_requisitos.md, 03_regras_de_negocio.md,
04_fluxos.md, 05_arquitetura.md, 06_modelo_dados.md,
07_api.md, 08_seguranca.md, 09_riscos.md, 10_backlog.md,
11_validacao.md, 12_roadmap.md, 13_deploy.md,
14_observability.md, 15_security_threats.md, 16_release_notes.md
```

### Sequential Thinking Integration
Usa Sequential Thinking MCP para decompor a validação em steps rastreáveis:
1. Collect required documents
2. Check presence and non-empty content
3. Record findings and unresolved issues
4. Publish validation summary

## Outputs

| Campo | Tipo | Descrição |
|---|---|---|
| `docs_qa` | object | {ok, missing[], empty[]} |
| `docs_qa_ok` | bool | True se tudo passou |

### Artefatos Gerados
- `docs/11_validacao.md` — Relatório de validação com status, missing, empty e trace de raciocínio

## Validation Rules
1. Pipeline status = `success` apenas se `ok` = true
2. Pipeline status = `failed` se qualquer documento estiver missing ou empty
3. Trace de Sequential Thinking deve ser incluído no relatório
4. Relatório deve listar explicitamente cada documento faltante

## Handoff
- **Sucesso** → Agent 09 (Project Extractor)
- **Falha** → Pipeline encerra com status `failed`

## Example

### Output (sucesso)
```json
{
  "docs_qa": {"ok": true, "missing": [], "empty": []},
  "docs_qa_ok": true,
  "status": "success"
}
```

### Output (falha)
```json
{
  "docs_qa": {"ok": false, "missing": ["docs/07_api.md"], "empty": ["docs/13_deploy.md"]},
  "docs_qa_ok": false,
  "status": "failed"
}
```
