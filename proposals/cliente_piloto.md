Objetivo: criar um sistema para receber propostas de projetos de clientes, validar viabilidade e gerar documentacao tecnica/comercial profissional antes do kickoff.

- Portal web para intake da proposta
- API backend para analise, score de valor e viabilidade
- Integracao com GitHub e Slack para notificacoes
- Checklist de requisitos, escopo e riscos
- Relatorio executivo com stack recomendada e estimativa

Prazo alvo: 8 semanas
Budget estimado: R$ 45.000
KPI: reduzir retrabalho de discovery em 40%
Requisito de seguranca: LGPD
